# SIL Translation Test

### Description
This repo is for documentation of SAB, RAB, DAB, KAB. And translating them into other languages via crowdin.


# How to Use
### Submitting
All submittions should be fodt files and be added (or modifed) in docs-en/fodt/<app builder name>/<file> for example "docs-en/fodt/SAB" 


### Crowdin Sync

###### Tokens
CROWDIN_PERSONAL_TOKEN: This can be created by clicking on the user's profile picture and selecting "settings", then find the "API" tab and clicking on it. Then selecting "New Token" under "Personal Access Tokens" and a token will be generated.

CROWDIN_PROJECT_ID: This can be found on the crowdin project webpage on the right hand side.

CROWDIN_GITHUB_TOKEN: This can be generated by clicking on the user's profile picture and selecting "settings", then scrolling down to find the "Developer Settings" tab and clicking on it. Then selecting "Tokens (classic)" under "Personal Access Tokens" and a select "Generate new token (classic)".


###### Syncing
Once the github workflow is run it will automatically copy the github odt files under docs-en into the Crowdin project.


### File Conversions
The github will automatically convert the files between fodt, odt, and pdf.
